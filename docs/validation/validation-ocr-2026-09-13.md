# OCR 时钟定位优化验证

日期：2026-09-13。本机 Python 3.14、Tesseract 5.5.0。

## 改动与校验

- 文本候选先按字符数量、基线排列、边框背景一致性和前景密度排序，再去除尺寸相近且高度重叠的框，最后应用 64 个候选上限。
- 标准、窄字、两种极性和四种翻转按候选排名交错尝试，大范围画面区域作为后备候选参与调度。
- 将候选发现时的首帧读数交给连续验证使用，每个候选的首帧不再重复 OCR。读数为零也能复用。
- 连续帧数量、原有 PTS 增量与残差规则、停表判断、取消和错误分类均沿用原规则。

实际 Tesseract 测试还覆盖窄字体、时钟上下方比分干扰、宽间距冒号、亮底深字、倒计时干扰、停表及两路独立 PTS 起点。检查识别值、连续样本、偏移与残差，并限制新增背景场景的 OCR 调用次数；耗时不作为跨机器断言。
