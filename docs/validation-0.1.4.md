# 0.1.4 足球取流、OCR 与线路切换验证

验证日期：2026-09-09。比赛页面使用匿名描述；本文不包含实际页面、直播间或媒体地址。真实画面、Cookie、请求头、签名媒体地址及调试脚本均仅保存在本机临时目录。

## 真实足球页面 A

按用户指定选择“高清直播5”，页面实际文字为“高清直播⑤”。页面还列有主播解说和其他高清线路，本次实际取流选择第五路。

原实现能打开页面并点击线路，但在 75 秒内无法确认源。检查发现：HTTPS 内嵌播放器请求 HTTP HLS，Chromium 将请求标记为 `mixed-content` 并拦截，原有嗅探只处理成功响应，因此没有可用候选。

修复后，正式嗅探流程将数字名称匹配到页面上的圈号名称，从被拦截的请求保留请求上下文，验证直播播放列表，再执行实际 ffprobe。该轮约 **22.1 秒**完成自动选线和验收；未修改 Chromium 的安全开关。

| 项目 | 实际结果 |
| --- | --- |
| 页面线路 | 高清直播⑤ |
| 播放列表 | HTTP 200，HLS 媒体列表；3 个分片，目标分片时长 2 秒，没有结束标记 |
| 视频 | H.264，1920×1080 |
| 音频 | AAC |
| 请求方式 | 比赛源直连；保留浏览器获取的 UA、Referer、Origin 和 Cookie 上下文 |
| 采样 | 实际 PyAV 解码，4 个关键帧；保留原始源 PTS |

浏览器自身仍受混合内容规则约束，以上成功指媒体探针读取及解码成功，并不将被拦截的浏览器播放器描述为已播放。

## 真实时钟 OCR

第一批画面中，计时位于比分牌下方。手动框选可以识别，但原自动定位只连接了部分数字；冒号前的间距使分钟部分与后半段分离。修复增加另一种横向文本连接宽度，同时保留小计时所需的窄连接方式。

下表是同批真实关键帧在修复后，**不提供 ROI、使用实际 Tesseract 自动定位**的结果。手动框选的读数与其一致。

| 6373.760 | 81:56 | −1457.760 |
| 6377.760 | 82:00 | −1457.760 |
| 6381.760 | 82:04 | −1457.760 |
| 6385.760 | 82:08 | −1457.760 |

自动识别已采集样本耗时 **5.421 秒**，4 帧全部形成连续走表序列，最大残差 **0 秒**。该耗时不含联网采样。自动 ROI 为 `[0.128125, 0.095833, 0.046094, 0.025]`，采用正常方向、标准预处理。

此次只验证单路足球源及 OCR。没有同场 B 站音源，未据此宣称双路同步精度或计算实际双路偏移；项目继续使用 `D = K_B - K_V`。后来该场比赛结束，修复前后对比使用此前保存的真实帧。

## 线路切换与回归范围

WebUI 增加首次连接时的线路名称和运行中的下拉切换；CLI 提供 `--video-line`，HTTP 提供 `POST /api/line`。名称匹配支持圈号、全角数字及空格。线路在 iframe 内或稍后加载时也会继续查找；未找到指定名称时等待重新选择。

切换中的旧画面在新源验收前继续运行。切换会使旧源 OCR 结果失效，自动模式重新测量；切换期间的新手动偏移优先。失败保留原源和当前偏移。“重新选线路”入口会等待人工选择，不立即复用上一线路。

本地浏览器回归使用合成 FLV 和实际 Chromium、ffprobe、FFmpeg、PyAV：从“中文高清”切换至 iframe 中的“高清直播⑤”，覆盖候选名称、Cookie 上下文、手动调整、源替换及 HLS 恢复。该类测试不代表另一条真实直播线路或实体手机验收。

测试还发现 libavformat 使用含显式端口的 HTTP authority 匹配 Cookie。修复保留普通域名 Cookie，并为当前源的显式端口增加对应域名条目，保留域名和路径约束。

完整回归：**154 passed，0 skipped，124.96 秒**。

```bash
FOOTBOY_FFMPEG=/path/to/ffmpeg \
FOOTBOY_FFPROBE=/path/to/ffprobe \
FOOTBOY_TESSERACT=/path/to/tesseract \
FOOTBOY_BROWSER_TESTS=1 \
python -m pytest -ra
```

上述回归包括合成时钟图片交给实际 Tesseract 的识别、媒体及浏览器流程，与前述真实足球采样分别记录。Ruff、格式、JavaScript 语法及 Git 差异检查通过；0.1.4 源码包与 wheel 构建成功，核对线路模块、控制页、hls.js、许可和版本，并确认没有包含状态、私有输入或测试产物。

## 环境与限制

- Linux x86_64 / WSL2，Python 3.14.4，PyAV 18.1.0，Playwright Chromium；FFmpeg / ffprobe 为 `N-126455-gecc7eb519e-20260907`。

- 自动列出线路依赖可见的文本控件；未知网站布局仍可能需要本机浏览器手选。受网站访问限制、失效或结束的源不能保证可用。
- 4 帧残差为 0 仅表示这批比赛时钟与源 PTS 一致，不代表长期误读率、双路听感或设备播放延迟的精度。
- 未完成不同来源同场足球的双路同步精度、实际长延迟缓冲、连续两小时或 Safari 连播 30 分钟验收。
